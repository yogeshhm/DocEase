> A simple doctor appointment management system where patients can book appointments and doctors can manage them through a dedicated dashboard.

---

## 🚀 Features

### 👤 Patient Side
- Book appointments with required details  
- Phone number validation  
- Track appointment status (Pending / Accepted / Rejected)  

### 👨‍⚕️ Doctor Dashboard
- View all appointment requests  
- Check patient details  
- Accept or reject appointments  

---

## 🛠️ Tech Stack

- **PHP** – Backend & logic  
- **MySQL** – Database  
- **JavaScript** – Form validation & UI behavior  
- **SCSS / CSS** – Styling  
- **HTML** – Structure
